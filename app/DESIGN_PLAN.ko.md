# 암행어흥 — 마패를 건 솔직한 리뷰

## 브랜드의 출발점

**도무지 못 믿을 리뷰, 이제는 암행어사가 직접 확인한다. 이 세상의 모든 작업 리뷰가 사라질 때까지.**

암행어흥은 선발된 어사를 현장에 파견해, 직접 경험한 솔직하고 대담한 기록을 남기는 서비스다. 리뷰어는 교육·실습·시험을 통과해야 활동 자격을 얻으며, 활동과 품질에 따라 등급을 쌓는다. 평가 변경 대가로 업장의 돈이나 혜택을 받는 행위에는 파면 원칙을 적용한다.

디자인의 기준은 암행어흥의 정체성과 높은 완성도다. 다른 서비스의 색상·레이아웃·브랜드 분위기를 기준으로 삼지 않는다.

## 역할별 경험

### 독자: 진짜 경험을 읽는 사람

홈의 순서: 출두 선언 → 세 가지 원칙 → 현장 기록 → 어사 선발 안내 → 어사 헌장.

리뷰 카드의 순서: 어사 닉네임·등급 → 구체적인 한 줄 판단 → 좋았던 점·아쉬운 점 → 방문 일시·업종 → 근거 표시 → 전체 기록.

상세는 방문 조건·사실·주관적 평가를 구분하고 사진·영수증 등의 **확인 상태**를 보여준다. 업체 답변과 정정 이력도 함께 읽을 수 있어야 한다. 강한 비판이나 낮은 점수만으로 노출을 우대하지 않는다.

### 어사: 시험으로 들어와 기록으로 증명하는 사람

교육 → 리뷰 실습 → 종합 시험 → 자격 확인 → 파견 지원 → 배정 → 현장 방문 → 근거 제출 → 품질 검토 → 공개 → 활동 보상.

활동 화면은 출두 대기 / 출두 중 / 기록 작성 / 검토 중 / 보완 요청 / 공개 완료를 구분한다. 시험 불합격과 자격 정지·파면은 다른 상태다.

| 표시 명칭 | 기존 코드 | 의미 |
|---|---|---|
| 초임 어사 | rookie | 선발을 통과하고 활동을 시작한 어사 |
| 정식 어사 | regular | 지속적인 활동과 품질을 쌓은 어사 |
| 상급 어사 | senior | 깊이 있는 관찰과 검증된 이력을 축적한 어사 |
| 수석 어사 | master | 장기간 책임 있는 기록을 이어온 어사 |

위 명칭은 브랜드 표현 기준이다. 현재 모든 등급 화면의 표시명을 일괄 변경한 것은 아니다. 서버의 승급 조건과 실제 상태를 유지하며 화면별로 전환한다. 시험 응시만으로 초임 자격을 부여하지 않는다.

### 업장: 솔직한 점검을 받아들이는 사람

업장 등록 → 방문 조건·점검 요청 → 어사 배정 → 현장 기록 → 답변·개선.

파견 비용으로 별점·긍정 문구·비판 삭제를 구매할 수 없다는 점을 요청 화면과 결제 요약에 명시한다. 실제 서비스에서는 배정의 독립성, 이해관계 확인, 업체 답변 권한, 이의 신청 절차를 서버까지 연결해야 한다.

## 어사 등급과 리뷰 수준의 분리

어사 등급은 사람의 활동 이력이다. 리뷰의 확인 표시는 한 건의 증거 상태다. 수석 어사의 글도 근거가 부족하면 별도로 표시하고 보완을 요청한다.

리뷰에 표시할 근거: 방문 확인 / 영수증 확인 / 사진 확인 / 보완 요청 / 확인 철회. 확인되지 않은 항목은 긍정 배지로 표시하지 않는다. `published` 상태를 `검증 완료`로 해석하지 않는다.

추가 설계할 리뷰 품질 등급은 근거 충실도·구체성·독자 유용성·정정 이력으로 평가한다. 평가가 좋거나 비판이 세다는 이유로 등급을 올리지 않는다. 품질 등급의 구체 명칭·산식은 확정 전 수치로 노출하지 않는다.

## 청탁·작업 리뷰와 파면

1. 금품·혜택·평가 개입 청탁을 제보하고 관련 기록을 제출한다.
2. 운영자가 근거를 확인하고 필요한 경우 파견·지급·신뢰 표시를 임시 제한한다.
3. 당사자 소명과 추가 자료를 받는다. 제보만으로 곧바로 위반 확정 표시를 하지 않는다.
4. 위반 판정과 사유를 기록한다. 해당 어사의 자격·배정 권한·관련 리뷰 표시를 함께 갱신한다.
5. 파면·정정·재심 이력을 보관하고 독자에게 필요한 상태를 설명한다.

이 내용은 브랜드의 원칙과 운영 설계다. 이번 작업에서 파면 집행 엔진과 관리자 심사 화면을 구현한 것은 아니다. 기존 탐지·신고·인증 API와의 연동을 검토해 아래 완료 조건을 충족해야 한다.

## 이번 변경과 검증 범위

- 기본 브랜드 이미지 5종 생성·저장·화면 연결.
- 브랜드 색상과 홈 선언 배너 변경, 마패 헤더 적용.
- 시작·온보딩·선발원에 생성 이미지와 새 브랜드 문구 적용.
- `/inspector-code`에 어사 선발·출두·청탁 배제 원칙 화면 추가.
- `design-preview.html`을 고유 브랜드 시안으로 전면 교체: 기록 필터·검색·상세, 선발 시험 체험, 등급, 출두 요청 절차, 어사 헌장.
- 시안의 업장·등급·리뷰 데이터는 명시된 가상 예시이며, 시험 체험은 실제 자격을 발급하지 않는다.
- 실제 결제·파면·파견 정책 집행의 완료를 주장하지 않는다. 브랜드 표현과 이미지는 구현했고, 운영 기능은 위 완료 조건에 따라 추가 검증해야 한다.

검증 결과는 `VALIDATION.md`에 기록한다.

## 실행 복구

일반 파일·명령 실행은 정상 응답을 확인했다. Flutter 명령은 사용자 캐시 쓰기·네트워크 권한 제한과 장시간 대기를 겪었다. 승인받은 이전 Flutter 분석 프로세스 41416을 중단했으며 SDK 파일은 수정하지 않았다. 이후 설치된 Flutter snapshot을 Dart의 별도 숨김 프로세스로 실행해 분석·테스트를 완료했다. 이것을 운영체제/샌드박스의 근본 원인까지 해결했다는 의미로 해석하지 않는다.

재실행 경로:

`powershell -NoProfile -File app/scripts/verify_quality.ps1 -CaptureScreens`

SDK가 다른 곳에 있으면 -FlutterSdk 인자를 지정한다. 이 스크립트는 설치된 SDK를 사용하며 분석, 선택적 화면 캡처, Flutter/Node 테스트를 순차 실행한다. SDK 캐시 접근이 허용되는 환경이 필요하다. 로그는 docs/qa에 남고 Git에서는 제외한다.

## 시각 검토

생성 시안 전체와 실제 Flutter home/search/report PNG를 확인했다. 홈과 보고서의 브랜드색·카드 계층·지적/약속 구분을 점검했다. 테스트용 아이콘 폰트 누락과 한글 폴백을 보완했다. 홈은 모든 크기에서 렌더/스크롤 예외가 없음을 검사했고, 모든 크기의 전체 스크롤 영역을 사람처럼 시각 검사한 것은 아니다. 검색·리포트의 큰 글자/실기기 전체 검증은 별도로 필요하다.

생성 시안은 운영 화면이 아니다. QA의 PNG는 실제 Flutter 위젯에 테스트 데이터를 주입한 렌더다. 한글 본문과 폴백은 이 컴퓨터의 맑은 고딕을 테스트에서만 사용한다. 해당 폰트를 앱에 추가하거나 재배포하지 않는다. 운영체제별 글자 모양은 달라질 수 있다.

HTML 보고서는 상단을 브라우저로 렌더링해 확인하고, 표·이미지·링크는 구조 검사했다. 전체 문서의 모든 화면 높이를 시각 검사한 것은 아니다.

## 검증하지 않은 것

실운영 DB·마이그레이션 적용, 실결제·송금, 로그인된 실제 단말, 전체 화면 접근성 인증, 운영 배포는 수행하지 않았다. 과거 fixed 기록의 사실 확인과 항목별 재감찰 확정 API는 후속 작업이다.
